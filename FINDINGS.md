# Security and robustness findings

The audit covered the tracked application, configuration, documentation, static assets, and npm lockfile. The credential scan found zero suspected secrets. The repository has no tracked CI workflows or generated build output. The production configuration exports static files, and the app has no request handlers or server-side drawing input. Severities reflect exposure in this app and its development toolchain.

The Excalidraw range starts at 0.17.6, the release that patched the published 0.17.x stored embed XSS. [CVE-2024-32472](https://github.com/advisories/GHSA-m64q-4jqh-f72f)
